# duels_won

Count of `event.type = 'DUEL'` with `outcome = 'WON'`, across **every**
duel sub-type (ground, aerial, tackle, sliding tackle, loose ball) —
overall physical/defensive success rate. See [tackles](tackles.md) and
[aerials](aerials.md) for the sub-type breakdowns; both are subsets of
this total, not additional events.

See [foundation_adjustments.md](foundation_adjustments.md) for `per_90`,
`possession`, and `opposition_strength`.
