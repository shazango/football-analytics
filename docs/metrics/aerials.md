# aerials

Count of `event.type = 'DUEL'` where `qualifiers.Duel = 'AERIAL'` **and**
`outcome = 'WON'` — aerial duels won, not attempted. Unlike
[tackles](tackles.md) (attempt volume), we report the won count here since
that's the conventional single-number "aerials" stat in scouting reports;
a contest-volume figure could be added later if needed.

See [foundation_adjustments.md](foundation_adjustments.md) for `per_90`,
`possession`, and `opposition_strength`.
