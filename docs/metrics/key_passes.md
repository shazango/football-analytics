# key_passes

Count of passes flagged by StatsBomb as a shot assist (`event.qualifiers.Pass
= 'SHOT_ASSIST'`) — a pass that led to a shot, whether or not that shot
scored. Distinct from [xa](xa.md), which weighs those same passes by how
good the resulting chance was rather than just counting them.

See [foundation_adjustments.md](foundation_adjustments.md) for `per_90`,
`possession`, and `opposition_strength`.
